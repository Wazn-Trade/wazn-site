ليه Wazn Screen

الحكم الشرعي على السهم لازم يكون قابل للمراجعة.

أغلب القوايم الشرعية بتديك «حلال» أو «حرام» من غير ما تقول ليه، ولا إمتى اتحدّثت، ولا على أي معيار. إحنا بنوريك الحسبة نفسها.

كل حكم معاه سببه

النسب المالية، والحدود، ورقم الصفحة في القوائم المالية، والمعيار اللي اتطبق. مفيش «ثق فينا».

صحيح في أي تاريخ

بيانات point-in-time: بيتحدّث مع كل مراجعة نصف سنوية لـ EGX33 ومع كل نتايج ربع سنوية. وتقدر تسأل: كان السهم ده متوافق يوم كذا؟

مبني للـ agents

REST API لتطبيقك، وMCP server يخلّي Claude أو أي AI agent يفحص محفظتك شرعيًا من المحادثة.

بيشتغل إزاي

ثلاث طبقات، والسهم لازم يعدّي عليهم كلهم.

أي شك في البيانات بيرفض السهم. القاعدة إننا نرفض لو مش متأكدين، ومش بنعدّي حاجة بالافتراض.

  1. عضوية EGX33 Shariah

    السهم لازم يكون في آخر مراجعة للمؤشر في التاريخ اللي بتسأل عنه. لو خرج منه، بيتعلّم «مستبعد» فورًا.

  2. نسب AAOIFI من القوائم المالية

    الدين الربوي، والنقدية الربوية، والإيراد غير المتوافق، محسوبين من آخر قوائم منشورة. ولو سهم قرب من الحد، بيتعلّم «تحت المراقبة» قبل المراجعة الجاية.

  3. الحكم والتطهير

    النتيجة (متوافق، أو تحت المراقبة، أو مستبعد) ومعاها الأسباب، ونسبة التطهير اللي تطبقها على التوزيعات.

للمطورين

سطر واحد في أي agent.

ضيف Wazn Screen كـ MCP server في Claude Desktop أو Claude Code أو أي client بيدعم MCP، أو استخدم الـ REST API مباشرة.

  • أدوات: screen_stock، sharia_universe، purification_calc، zakat_calc
  • كل رد فيه as_of وsource وreasons
  • Read-only: مفيش أي صلاحية تداول، ومفيش أي توصيات شراء
